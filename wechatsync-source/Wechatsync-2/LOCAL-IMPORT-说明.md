# 文章同步助手 · 本地导入试用版

基于 wechatsync/Wechatsync v2 公开源码，版本 2.0.9.1。原项目：https://github.com/wechatsync/Wechatsync

## 安装到你平时登录账号的 Chrome

这不是商店原版的在线升级，不会自动覆盖原版。首次安装需要你手动确认扩展权限。

1. 在 Chrome 地址栏输入 `chrome://extensions/`。
2. 打开“开发者模式”，点“加载已解压的扩展程序”。
3. 选择本交付文件夹内的 `安装插件` 文件夹（里面有 manifest.json）。不要选择 ZIP 文件，也不要选择整个源码目录。
4. 为避免两个版本同时接管页面，试用时建议先暂停原版“文章同步助手”。不要清理 Chrome Cookie 或登录资料。
5. 点“文章同步助手 · 本地导入试用版”，再点“导入本地文章 / 发布包”。

权限说明：继承原项目的网页访问、Cookie、脚本、标签页和存储等权限，范围较广。它利用当前 Chrome 的登录状态访问所选平台。不要将 Cookie、账号密码或扩展 Token 发给陌生人。此本地构建未配置分析服务密钥。原项目自带更新检查；请勿用原版安装包覆盖此定制版，否则会失去本地导入功能。

## 使用

1. 单篇 Word：选择 `.docx`，下拉框选择该正文，再点“读取并预览”。内嵌图片会自动读取；旧 `.doc` 请先另存为 `.docx`。
2. MD/HTML 发布包：点“选择发布包文件夹”，然后在下拉框明确选择正文文件。不会擅自把SEO、原文备份等文件合并成正文。
3. 相对路径或中文图片名会对应到所选文件夹中的图片。缺图、同名图片无法唯一匹配时会阻止同步。可以“补充本地图片”后重新读取。
4. 查看标题、正文、图片顺序及图片数量。只在勾选时移除开头与标题完全相同的一级标题，不进行AI改写。
5. 勾选平台，点“检查所选平台登录状态”，确认显示的账号正确。
6. 点“确认并同步到草稿”，再次确认文章、图片和账号。逐个平台处理，失败停止，不自动重试。
7. 打开返回的草稿链接，核对配图、分类、AI声明等平台设置，再由你点击发布。

不要在同步中关闭页面。失败或超时后先检查草稿箱，可能已留下空草稿或部分上传的图片，不要立即重复提交。

## 当前支持与限制

- 本地输入：DOCX、Markdown、HTML；PNG/JPEG/GIF/WebP配图。
- 每篇源文件不超过15MB，正文和嵌入图片约24MB上限。Word复杂排版、字体和分页转换后可能变化。
- 导入预览不请求网络图片。网络图片需要你先下载，再作为本地图片选入；未找到图片时不允许同步。
- 本地入口开放：搜狐、知乎、掘金、CSDN、B站专栏、微信公众号、博客园、51CTO、慕课网、开源中国、SegmentFault。它们的公开源码有草稿保存路径，但并未使用你的账号逐个平台实测。
- 网易、头条、小红书的适配器不在本次获取的公开代码中，不能宣称支持。商店原版的平台列表可能比这个源码构建版多。
- 你原有的官网、百家号发布助手、Excel登记和文件夹归档程序完全未改动。本插件保存草稿不算发布，不会登记Excel，不会移动文件夹。
- 尚未专门对接各平台AI内容声明、分类、营销电话等字段，请在草稿中人工核对。
- 插件不能保证平台不触发风控；遇到验证码、限流、服务异常请停止，交由你在正常网页上处理。

## 验证与维护

本地导入12项离线测试覆盖：中文与编码路径、MD元数据、Word内嵌图片、顺序/ALT、重复标题、缺图、重名图片、文件大小、HTML清理、平台图片预处理、上传错误停止。构建通过。Chrome离线界面测试也通过：文件选择、中文与图片预览、取消上传不发送、确认后草稿消息、缺图禁用按钮；平台响应全部模拟，没有向真实账号上传。真实账号发布需要安装后另行验证。

源码包包含修改后的代码和 pnpm-lock.yaml，遵循上游 GPL-3.0；原始 LICENSE 随包提供。

开发构建：`pnpm install --frozen-lockfile --ignore-scripts`，然后 `pnpm --filter @wechatsync/extension build`。
测试：在 packages/extension 下运行 `node node_modules/vitest/vitest.mjs run --config vitest.local.config.ts`。
离线界面测试：同目录运行 `node tests/ui-smoke.mjs`，需要系统 Chrome 和 Playwright，平台请求全部模拟。

回退：关闭或移除本地导入试用版，再启用商店原版即可。移除插件会删除该插件本地历史，不会删除平台草稿。
